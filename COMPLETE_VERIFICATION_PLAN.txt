═══════════════════════════════════════════════════════════════════════════════
                           THE 7-STEP PROCESS
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Start Backend Server
─────────────────────────────
  Command: docker-compose up -d
  OR:      cd server && npm run dev
  
  Verify:  curl http://localhost:5000/health
  
  Success: See JSON response with "status": "healthy"

STEP 2: Start Frontend Server
──────────────────────────────
  Command: npm run dev
  
  Verify:  See message "Local: http://localhost:5173/"
  
  Success: Terminal shows Vite dev server running

STEP 3: Open Browser
────────────────────
  URL:     http://localhost:5173
  
  Verify:  App loads without errors
  
  Success: See SEMS interface

STEP 4: Open Browser Console
────────────────────────────
  Windows: Ctrl + Shift + J
  Mac:     Cmd + Option + J
  
  Verify:  Console tab is open
  
  Success: See browser console messages

STEP 5: Look for Connection Message
───────────────────────────────────
  Expected: [SEMS Socket] Connected successfully
  
  Also look for:
    [SEMS API] Base URL: http://localhost:5000/api
    [SEMS Socket] Connected to /location namespace
    [SEMS Socket] Connected to /emergency namespace
  
  Success: If you see "Connected successfully" → CONNECTION WORKS!

STEP 6: Test User Registration
───────────────────────────────
  In console, paste:
  
  fetch('http://localhost:5000/api/auth/register', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      name: 'Test User',
      email: 'test@test.com',
      phone: '9999999999',
      password: 'password123'
    })
  }).then(r => r.json()).then(d => console.log(d))
  
  Expected: "success": true in response
  
  Success: If you see success true → API works!

STEP 7: Test Login
──────────────────
  In console, paste:
  
  fetch('http://localhost:5000/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      email: 'test@test.com',
      password: 'password123'
    })
  }).then(r => r.json()).then(d => {
    console.log(d);
    if(d.data?.token) localStorage.setItem('token', d.data.token);
  })
  
  Expected: "success": true + token is returned
  
  Success: If token is saved → Authentication works!

═══════════════════════════════════════════════════════════════════════════════
                        TROUBLESHOOTING QUICK LINKS
═══════════════════════════════════════════════════════════════════════════════

"Cannot connect to localhost:5000"
  → Check if backend is running
  → Run: curl http://localhost:5000/health
  → If fails: Restart backend
  → See: VERIFY_CONNECTION.md → Issue 1

"CORS error" in browser console
  → Frontend cannot reach backend
  → Check server/.env has CORS_ORIGIN=http://localhost:3000
  → Restart backend
  → See: VERIFY_CONNECTION.md → Issue 2

"Socket.IO not connecting"
  → Real-time connection failed
  → Clear browser cache: Ctrl+Shift+Delete
  → Refresh page
  → See: VERIFY_CONNECTION.md → Issue 3

"401 Unauthorized"
  → Authentication token is invalid
  → Clear localStorage: localStorage.clear()
  → Register and login again (Step 6-7)
  → See: VERIFY_CONNECTION.md → Issue 4

"Port 5000 already in use"
  → Another process is using the port
  → Run: lsof -i :5000
  → Kill process: kill -9 <PID>
  → Restart backend
  → See: VERIFY_CONNECTION.md → Issue 5
