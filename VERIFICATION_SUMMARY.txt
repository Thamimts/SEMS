TROUBLESHOOTING:

Problem: Cannot connect to localhost:5000
  → Check if backend is running: curl http://localhost:5000/health
  → Restart: docker-compose up -d

Problem: CORS error in console
  → Restart backend, should fix automatically

Problem: Socket not connecting  
  → Clear cache: Ctrl+Shift+Delete, then refresh

Problem: 401 Unauthorized
  → Re-login by running Step 5 & 6 again

Problem: Port already in use
  → Kill process: lsof -i :5000 then kill -9 <PID>
